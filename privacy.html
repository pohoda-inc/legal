プライバシーポリシー

制定日：2026年6月9日 ／ 最終改定：2026年10月2日

杉本 啓輔（屋号：Pohoda。以下「当方」）は、当方が提供する iOS/macOS アプリケーション「KATACHI」「Keep In Touch」「Glidwell」「Graph」「One CRM」「Utility」および「YANE」（iOS アプリと Web サービス yane.pohoda.jp を含みます。以下あわせて「本アプリ」）における個人情報の取扱いについて、以下のとおり定めます。

1. 基本方針

本アプリは「ローカルファースト」を原則とします。ユーザーがアプリ内で記録する情報は、原則としてユーザーのデバイス内にのみ保存され、当方のサーバーには送信されません。当方がこれらの記録内容を閲覧・取得することはできません。本アプリは広告を表示せず、ユーザーの行動を他社サービスをまたいで追跡（トラッキング）しません。分析 SDK・トラッキング SDK は使用していません。

2. アプリごとの取扱い

KATACHI

2-1. アプリ内で記録される情報

トレーニング記録、体重・体脂肪などの体組成、体型写真は、すべてユーザーのデバイス内にのみ保存されます。当方のサーバーには送信されません。

2-2. iCloud バックアップ（任意・Pro）

ユーザーが iCloud バックアップを有効にした場合、上記の記録はユーザー自身の iCloud（Apple のプライベートデータベース）に同期されます。これはユーザーの Apple アカウント内に保存されるものであり、当方がアクセスすることはできません。

2-3. ヘルスケア連携（任意・Pro）

ユーザーが許可した場合に限り、Apple の「ヘルスケア」から体重・体脂肪のデータを読み取り、本アプリの記録として取り込みます。読み取ったデータは端末内に保存され、外部に送信されません。

2-4. 課金情報

KATACHI Pro（月額・年額・買い切り）の購入・更新・復元はApple の StoreKit を通じてのみ行われます。当方は、購入状態の判定に必要な範囲で Apple から提供される情報を参照しますが、クレジットカード番号その他の決済情報を取得しません（Apple が処理します）。KATACHI は購入管理のための第三者サービス（外部の課金プラットフォーム等）を利用していません。

Keep In Touch

2-5. アプリ内で記録される情報

ユーザーが記録するコンタクト情報（氏名・ニックネーム・誕生日・写真・連絡履歴・メモ等）は、すべてユーザーのデバイス内にのみ保存されます。当方のサーバーには送信されず、当方が閲覧・取得することはできません。

2-6. 課金情報

ベーシックプラン（月額・年額・買い切り）の購入・更新・復元はApple の StoreKit を通じてのみ行われます。当方はクレジットカード番号その他の決済情報を取得しません（Apple が処理します）。Keep In Touch は購入管理のための第三者サービス（外部の課金プラットフォーム等）を利用していません。

Glidwell

2-7. アプリ内で記録される情報

ユーザーが記録する選考・案件・活動・書類などの情報は、すべてユーザーのデバイス内に保存されます。中核機能（選考管理・通知・書類・バックアップ）はネットワーク通信を行わず、当方のサーバーには送信されません。通知はローカル通知のみで、外部送信はありません。

2-8. AI アシスタント（任意・既定オフ）

AI 機能はユーザーが明示的に有効化した場合に限り動作します。ご利用の場合のみ、企業名・氏名・連絡先などを送信前に伏字へ置き換えた上で、データを学習に使用しない AI 提供者へ送信します（非学習・ゼロ保持を予定）。送信内容は実行前に確認でき、いつでも設定からオフにできます。

2-9. 課金情報

サブスクリプション（スタンダード／プロ）および AI クレジットの購入・更新はApple の StoreKit を通じてのみ行われます。当方はクレジットカード番号その他の決済情報を取得しません（Apple が処理します）。

Graph

2-10. アプリ内で記録される情報

ユーザーが入力する数値・グラフの設定・メモ等は、すべてユーザーのデバイス内（SwiftData）に保存されます。ネットワーク通信を行わず、当方のサーバーには送信されません。入力の処理もすべて端末内で行い、AI や外部サービスは使用しません。CSV 書き出しは、ユーザーの操作によりデバイス内に出力されます。

2-11. 課金情報

サポータープラン（買い切り／年額）の購入・更新はApple の StoreKit を通じてのみ行われます。当方はクレジットカード番号その他の決済情報を取得しません（Apple が処理します）。購入管理のための第三者サービスは利用していません。

One CRM

2-12. アプリ内で記録される情報

ユーザーが記録する顧客・取引先・担当者・案件・活動・タスク・メモ・写真などの情報は、すべてユーザーのデバイス内（SwiftData）にのみ保存されます。ネットワーク通信を行わず、当方のサーバーには送信されず、当方が閲覧・取得することはできません。バックアップ・CSV の書き出しは、ユーザーの操作によりデバイス内にファイルとして出力されます。分析 SDK・広告 SDK は使用していません。

2-13. 連絡先・写真・生体認証

「連絡先から取り込む」を選んだ場合に限り、ユーザーが選んだ連絡先を端末内で読み取って登録します（外部送信はありません）。写真は端末の写真選択画面から選んだものだけを端末内に保存します。アプリロックは Face ID / Touch ID / パスコードによる端末の認証機能を利用し、生体情報を当方が取得することはありません。

2-14. Apple Intelligence（任意）

対応端末で Apple Intelligence が有効な場合に限り、自然文での検索・登録・質問に、Apple が端末上で動作させるオンデバイスの言語モデル（Foundation Models）を利用できます。入力内容と記録の一部はこの処理のために端末内でモデルへ渡されますが、当方のサーバーや第三者には送信されません。Apple Intelligence が使えない端末・設定では、この機能は利用できません（他の機能に影響はありません）。

2-15. 課金情報

Pro プラン（月額・年額・買い切り）の購入・更新・復元はApple の StoreKit を通じてのみ行われます。当方はクレジットカード番号その他の決済情報を取得しません（Apple が処理します）。購入管理のための第三者サービスは利用していません。

Utility

2-16. メモ・タスクについて記録される情報

ユーザーが記録するメモ・タスクは、すべてユーザーのデバイス内（SwiftData）に保存され、当方のサーバーとの通信は行わず、当方が閲覧・取得することはできません。ユーザーが許可した場合、端末の「カレンダー」（EventKit）から予定を読み取り・作成・編集しますが、予定データは Apple のカレンダーサービスが管理するものであり、当方には送信されません。

2-17. iCloud 同期・バックアップ（メモ・タスクのみ）

メモ・タスクのデータは、ユーザー自身の iCloud（Apple のプライベートデータベース。CloudKit）に同期され、同じ Apple ID でサインインした他の端末（iPhone・iPad・Mac）と共有されます。また、ユーザーの iCloud Drive（このアプリ専用のコンテナ）に日付付きのバックアップファイルを自動または手動で保存します。いずれもユーザー自身の iCloud 内に保存されるものであり、当方がアクセスすることはできません。健康記録（次項）はこの iCloud 同期・バックアップの対象に含まれません。

2-18. 健康記録について（端末内のみ・iCloudには保存しません）

体重・体脂肪率の手入力記録、および（iOS/iPadOSで許可した場合のみ）「ヘルスケア」から読み取る歩数・体重・体脂肪率は、その端末のローカルストアにのみ保存され、iCloud への同期も iCloud Drive へのバックアップも行いません（Apple の App Store 審査ガイドラインに基づき、個人の健康情報は iCloud に保存しない方針としています）。設定で有効にした場合は、本アプリで記録した体重・体脂肪率を「ヘルスケア」へ書き戻します。読み取り・書き戻しとも端末内で完結し、外部への送信や広告目的での利用はありません。ユーザーがCSV書き出し（共有シートでの明示的な操作）を行った場合は、その書き出しファイルに健康記録が含まれます。

2-19. 通知

リマインダー通知はローカル通知のみで、外部送信はありません。

2-20. 課金情報

サポータープラン（年額）・買い切りプランの購入・更新・復元はApple の StoreKit を通じてのみ行われます。当方はクレジットカード番号その他の決済情報を取得しません（Apple が処理します）。購入管理のための第三者サービスは利用していません。

YANE

2-21. アプリ内で記録される情報

物件の名前・住所・費用・メモ・内見チェック・写真は、ユーザーのデバイス内にのみ保存され、当方のサーバーには送信されません。分析 SDK・広告 SDK は使用していません。

2-22. 災害リスク・周辺データの取得

災害リスク・明治期の低湿地・標高の判定のため、物件の位置を含む地図タイルの画像を、ハザードマップポータルサイト・国土地理院のサーバーから取得します。取得に使うのはタイルの番号（数百メートル四方の区画）で、住所や物件の情報は送りません。

周辺データ（学区・周辺施設・法規制・相場・地形・地震など）の取得のため、物件の緯度・経度と判定の精度を、当方の中継サーバー（api.pohoda.jp、Cloudflare 社のサービス上で運用）に送信します。中継サーバーは国土交通省「不動産情報ライブラリ」・国土地理院・防災科学技術研究所（J-SHIS）から必要なデータを取得して返すだけで、緯度・経度を保存・記録しません。

無料版の利用上限を守るため、アプリはインストールごとに作る乱数（個人を特定する情報とは結びつかない識別子）を中継サーバーに送ります。中継サーバーは、この識別子と接続元の IP アドレスから作った「元に戻せない値」（その日だけの乱数と組み合わせて要約したもの）で、その日の利用回数を数えます。識別子や IP アドレスそのものは保存せず、この値も翌日に削除します。

2-23. 住所の検索

住所や駅名の検索には、Apple の地図検索（MapKit）を利用します。検索の内容は Apple のプライバシーポリシーに従って扱われます。

2-24. 課金情報

Pro（買い切り）の購入・復元はApple の StoreKit を通じてのみ行われます。当方はクレジットカード番号その他の決済情報を取得しません。Pro をご利用の場合は、無料版の利用上限の対象外とするため、App Store の購入情報（Apple が署名した取引情報）を中継サーバーに送信します。中継サーバーは署名を確かめるためだけに使い、短期間（最長1日）の確認結果だけを保持します。氏名・メールアドレス・支払い情報は含まれません。

2-25. Web サービス（yane.pohoda.jp）

Web サービスで登録した物件の情報・内見メモ・写真は、ご利用のブラウザの中（IndexedDB・localStorage）にのみ保存され、当方のサーバーには送信されません。ブラウザのサイトデータを消去すると削除されます。災害リスク・周辺データの取得は 2-22 と同じ方法で行います。住所の検索には国土地理院の住所検索を利用します。

購入：Pro（Web）の決済は Stripe, Inc. の決済画面で行います。メールアドレスとカード情報は Stripe が取得・処理し、当方はカード番号を取得しません。決済後、当方は Stripe に支払いの状態を確かめ、Pro を有効にするための署名つきの値（ライセンス）を発行してブラウザに保存します。ライセンスには購入の識別番号が含まれ、氏名・メールアドレスは含まれません。返金された購入は、識別番号を失効の管理に使います。

購入の復元：復元のために入力されたメールアドレスは、Stripe でそのアドレスの購入を確かめるため、および復元リンクのメールを送るため（Resend, Inc. を利用）にのみ使い、当方のサーバーには保存しません。

利用状況の合計：サービスの改善のため、画面の操作（物件の追加・購入画面を開いた・購入した など）があったことを、決まった名前だけで中継サーバーに送り、日ごとの合計として数えます。物件・住所・メールアドレス・識別子・IP アドレスは送らず、記録しません。

不正な利用の防止：購入・復元の画面では、自動プログラムによる不正な利用を防ぐため Cloudflare Turnstile を利用します。Turnstile はブラウザの情報を Cloudflare 社のプライバシーポリシーに従って扱います。

3. 利用目的

  • 本アプリの機能提供
  • サブスクリプションの有効状態の判定・管理
  • 不具合対応・ユーザーサポート

4. 第三者提供・業務委託

法令に基づく場合を除き、第三者に個人情報を提供しません。本アプリの運営に必要な範囲で、以下のサービスを利用します。

  • Apple Inc.（App Store 決済処理／iCloud。全アプリ共通）
  • Cloudflare, Inc.（YANE の中継サーバー・Web サービスの運用、Turnstile による不正利用の防止。緯度・経度は保存しません）
  • Stripe, Inc.（YANE の Web サービスの決済処理）
  • Resend, Inc.（YANE の Web サービスの購入の復元メールの送信）
  • AI 提供者（Glidwell の AI 機能を利用する場合のみ。送信前にマスキングし、送信データを学習に使用しない事業者を利用します。中核機能では利用しません）

5. 保存期間

  • アプリ内記録情報：ユーザーがアプリ内で削除するか、アプリをアンインストールするまで（デバイス内に保存。iCloud バックアップ有効時はユーザーの iCloud 内）
  • YANE の中継サーバーの利用回数の値・購入の確認結果：翌日まで（最長1日）
  • YANE の Web サービスで返金された購入の識別番号：失効の管理に必要な期間
  • YANE の Web サービスの決済の記録：Stripe が法令とその規約に従って保持します

6. ユーザーの権利

  • アプリ内記録情報の削除（アプリ内の操作、またはアンインストール）
  • iCloud バックアップの無効化（KATACHI：設定から）

7. トラッキング・広告について

本アプリは広告を表示せず、ユーザーの行動を他社サービスをまたいで追跡（トラッキング）しません。分析 SDK・トラッキング SDK は使用していません。

8. お子様の利用について

本アプリは 13 歳以上の利用を想定しています。13 歳未満が利用する場合は保護者の同意のもとご利用ください。

9. 改定

本ポリシーは予告なく改定されることがあります。重要な変更がある場合はアプリ内または本ウェブサイトで通知します。
