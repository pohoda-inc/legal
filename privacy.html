プライバシーポリシー

制定日：2026年6月9日 ／ 最終改定：2026年11月20日

杉本 啓輔（屋号：Pohoda。以下「当方」）は、当方が提供する iOS/macOS アプリケーション「KATACHI」「Keep In Touch」「Glidwell」「Graph」「One CRM」「Utility」「Costs」および「YANE」（iOS アプリと Web サービス yane.pohoda.jp を含みます。以下あわせて「本アプリ」）における個人情報の取扱いについて、以下のとおり定めます。

1. 基本方針

本アプリは「ローカルファースト」を原則とします。ユーザーがアプリ内で記録する情報は、原則としてユーザーのデバイス内にのみ保存され、当方のサーバーには送信されません。当方がこれらの記録内容を閲覧・取得することはできません。本アプリは広告を表示せず、ユーザーの行動を他社サービスをまたいで追跡（トラッキング）しません。分析 SDK・トラッキング SDK は使用していません。

2. アプリごとの取扱い

KATACHI

2-1. アプリ内で記録される情報

トレーニング記録、体重・体脂肪などの体組成、体型写真は、すべてユーザーのデバイス内にのみ保存されます。当方のサーバーには送信されません。

2-2. iCloud バックアップ（任意・Pro）

ユーザーが iCloud バックアップを有効にした場合、上記の記録はユーザー自身の iCloud（Apple のプライベートデータベース）に同期されます。これはユーザーの Apple アカウント内に保存されるものであり、当方がアクセスすることはできません。ただし、ヘルスケアから取り込んだ体重・体脂肪の値は iCloud に保存せず、端末内にのみ保存します（手入力した値は同期の対象です）。

2-3. ヘルスケア連携（任意・Pro）

ユーザーが許可した場合に限り、Apple の「ヘルスケア」から体重・体脂肪のデータを読み取り、本アプリの記録として取り込みます。読み取ったデータは端末内に保存され、外部に送信されません。

2-4. トレーナーとの連携（任意）

ユーザーが、KATACHI + を使うトレーナー（店舗）から招待を受け、送る項目を自分で選んで同意した場合に限り、次のとおり記録を共有します。共有は Apple の iCloud（CloudKit の共有機能）を通じて行われ、当方のサーバーを経由せず、当方が閲覧することはできません。

  • トレーナーに送る情報：ユーザーが選んだ項目の記録だけです（筋トレの自主練＝日付・種目・重量・回数、有酸素＝日付・時間・速度・傾斜）。選んだ開始日より前の記録と、「この記録は共有しない」にした記録は送りません。
  • 送らない情報：体重・体脂肪・ヘルスケアから取り込んだ値・メモ・写真は、どの設定でも送りません。
  • 見られる人：連携先の店舗のスタッフ全員です。送った記録は、店舗のオーナーの iCloud に保存されます。
  • 受け取る情報：トレーナーが共有したセッションの記録とメニューを表示します。ユーザー自身の記録とは混ぜません。
  • 招待に使う情報：招待には、ユーザーの Apple アカウントのメールアドレス（トレーナーが入力します）が使われます。
  • やめるとき：項目をオフにする・連携をやめると、送った記録は店舗側から削除されます。ただし、店舗がすでに書き出した PDF などは取り消せません。

2-5. 課金情報

KATACHI Pro（年額・買い切り）の購入・更新・復元はApple の StoreKit を通じてのみ行われます。当方は、購入状態の判定に必要な範囲で Apple から提供される情報を参照しますが、クレジットカード番号その他の決済情報を取得しません（Apple が処理します）。KATACHI は購入管理のための第三者サービス（外部の課金プラットフォーム等）を利用していません。

2-9. AI アシスタント（任意）

模擬面接の読み上げと音声入力には、Apple が提供する端末の機能を使います。

バージョン 1.6 以前のアプリでは、伏字化した内容をデータを学習に使用しない AI 提供者へ、読み上げる文章を音声合成の提供者へ送信します。最新版へのアップデート後は送信しません。

One CRM

2-13. アプリ内で記録される情報

ユーザーが記録する顧客・取引先・担当者・案件・活動・タスク・メモ・写真などの情報は、ユーザーのデバイス内（SwiftData）に保存されます。iCloud 同期がオン（初期設定）のときは、ユーザー自身の iCloud（Apple の CloudKit。プライベートデータベース）にも保存され、同じ Apple アカウントでサインインした iPhone・iPad・Mac の間で同じ内容になります。同期はアプリの「カスタマイズ」からいつでもオフにできます。いずれの場合も当方のサーバーには送信されず、当方が閲覧・取得することはできません。バックアップ・CSV の書き出しは、ユーザーの操作によりデバイス内にファイルとして出力されます。分析 SDK・広告 SDK は使用していません。

チームで使う（共有）機能（日本の App Store でのみ提供・Pro）：ユーザーがビジネスを共有した場合、そのビジネスの記録は Apple の CloudKit の共有の仕組みにより、招待された相手（参加者）の端末にも表示され、参加者も記録を追加・編集できます。共有したデータは共有したユーザー（オーナー）の iCloud に保存され、当方はアクセスできません。参加者の追加・削除と共有の停止はオーナーが行います。共有をやめた場合や参加者を外した場合、参加者の端末からそのビジネスは消えますが、参加者が事前に書き出したファイルなど、端末の外に出たデータは消えません。また、1つの購入を複数人で使い回すことを防ぐため、共有したビジネスには参加者ごとに、iCloud のユーザー識別子と購入情報から作った識別値（元に戻せない値）を保存します。この値もオーナーの iCloud 内にあり、当方は取得しません。

2-14. 連絡先・写真・生体認証

「連絡先から取り込む」を選んだ場合に限り、ユーザーが選んだ連絡先を端末内で読み取って登録します。写真は端末の写真選択画面から選んだものだけを保存します。取り込んだ連絡先・写真は他の記録と同じく、端末内と、iCloud 同期がオンのときはユーザー自身の iCloud に保存され、当方には送信されません。アプリロックは Face ID / Touch ID / パスコードによる端末の認証機能を利用し、生体情報を当方が取得することはありません。

Utility

2-17. メモ・タスクについて記録される情報

ユーザーが記録するメモ・タスクは、すべてユーザーのデバイス内（SwiftData）に保存され、当方のサーバーとの通信は行わず、当方が閲覧・取得することはできません。ユーザーが許可した場合、端末の「カレンダー」（EventKit）から予定を読み取り・作成・編集しますが、予定データは Apple のカレンダーサービスが管理するものであり、当方には送信されません。

2-18. iCloud 同期・バックアップ（メモ・タスクのみ）

メモ・タスクのデータは、ユーザー自身の iCloud（Apple のプライベートデータベース。CloudKit）に同期され、同じ Apple ID でサインインした他の端末（iPhone・iPad・Mac）と共有されます。また、ユーザーの iCloud Drive（このアプリ専用のコンテナ）に日付付きのバックアップファイルを自動または手動で保存します。いずれもユーザー自身の iCloud 内に保存されるものであり、当方がアクセスすることはできません。健康記録（次項）はこの iCloud 同期・バックアップの対象に含まれません。

2-19. 健康記録について（端末内のみ・iCloudには保存しません）

体重・体脂肪率の手入力記録、および（iOS/iPadOSで許可した場合のみ）「ヘルスケア」から読み取る歩数・体重・体脂肪率は、その端末のローカルストアにのみ保存され、iCloud への同期も iCloud Drive へのバックアップも行いません（Apple の App Store 審査ガイドラインに基づき、個人の健康情報は iCloud に保存しない方針としています）。設定で有効にした場合は、本アプリで記録した体重・体脂肪率を「ヘルスケア」へ書き戻します。読み取り・書き戻しとも端末内で完結し、外部への送信や広告目的での利用はありません。ユーザーがCSV書き出し（共有シートでの明示的な操作）を行った場合は、その書き出しファイルに健康記録が含まれます。

YANE

2-22. アプリ内で記録される情報

物件の名前・住所・費用・メモ・内見チェック・写真は、ユーザーのデバイス内にのみ保存され、当方のサーバーには送信されません。分析 SDK・広告 SDK は使用していません。

2-23. 災害リスク・周辺データの取得

災害リスク・明治期の低湿地・標高の判定のため、物件の位置を含む地図タイルの画像を、ハザードマップポータルサイト・国土地理院のサーバーから取得します。取得に使うのはタイルの番号（数百メートル四方の区画）で、住所や物件の情報は送りません。

周辺データ（学区・周辺施設・法規制・相場・地形・地震など）の取得のため、物件の緯度・経度と判定の精度を、当方の中継サーバー（api.pohoda.jp、Cloudflare 社のサービス上で運用）に送信します。中継サーバーは国土交通省「不動産情報ライブラリ」・国土地理院・防災科学技術研究所（J-SHIS）から必要なデータを取得して返すだけで（物件の地点の町丁目名を調べるため、国土地理院の逆ジオコーダにも緯度・経度を送ります）、緯度・経度を保存・記録しません。

無料版の利用上限を守るため、アプリはインストールごとに作る乱数（個人を特定する情報とは結びつかない識別子）を中継サーバーに送ります。中継サーバーは、この識別子と接続元の IP アドレスから作った「元に戻せない値」（その日だけの乱数と組み合わせて要約したもの）で、その日の利用回数を数えます。識別子や IP アドレスそのものは保存せず、この値も翌日に削除します。

2-24. 住所の検索

住所や駅名の検索には、Apple の地図検索（MapKit）を利用します。検索の内容は Apple のプライバシーポリシーに従って扱われます。

2-25. 課金情報

Pro（1年間。以前の買い切りを含みます）の購入・復元はApple の StoreKit を通じてのみ行われます。当方はクレジットカード番号その他の決済情報を取得しません。Pro をご利用の場合は、無料版の利用上限の対象外とするため、App Store の購入情報（Apple が署名した取引情報）を中継サーバーに送信します。中継サーバーは署名を確かめるためだけに使い、短期間（最長1日）の確認結果だけを保持します。氏名・メールアドレス・支払い情報は含まれません。

2-26. Web サービス（yane.pohoda.jp）

Web サービスで登録した物件の情報・内見メモ・写真は、ご利用のブラウザの中（IndexedDB・localStorage）にのみ保存され、当方のサーバーには送信されません。ブラウザのサイトデータを消去すると削除されます。災害リスク・周辺データの取得は 2-23 と同じ方法で行います。住所の検索には国土地理院の住所検索を利用します。

購入：Pro（Web）の決済は Stripe, Inc. の決済画面で行います。メールアドレスとカード情報は Stripe が取得・処理し、当方はカード番号を取得しません。決済後、当方は Stripe に支払いの状態を確かめ、Pro を有効にするための署名つきの値（ライセンス）を発行してブラウザに保存します。ライセンスには購入の識別番号が含まれ、氏名・メールアドレスは含まれません。返金された購入は、識別番号を失効の管理に使います。

購入の復元：復元のために入力されたメールアドレスは、Stripe でそのアドレスの購入を確かめるため、および復元リンクのメールを送るため（Resend, Inc. を利用）にのみ使い、当方のサーバーには保存しません。

利用状況の合計：サービスの改善のため、画面の操作（物件の追加・購入画面を開いた・購入した など）があったことを、決まった名前と、最初に開いたページの区分（読みものの記事名・無料チェック・検索・直接 など）だけで中継サーバーに送り、日ごとの合計として数えます。購入時は同じ区分を Stripe の決済の記録に添え、どの記事から購入されたかの集計に使います。区分はブラウザ（localStorage）にも保存します。物件・住所・メールアドレス・識別子・IP アドレスは送らず、記録しません。

不正な利用の防止：購入・復元の画面では、自動プログラムによる不正な利用を防ぐため Cloudflare Turnstile を利用します。Turnstile はブラウザの情報を Cloudflare 社のプライバシーポリシーに従って扱います。

Dayglyph

2-31. ヘルスケアのデータ

Dayglyph は、ユーザーの許可を得たうえで、Apple Watch のヘルスケア（HealthKit）から睡眠の記録・心拍変動（HRV）・睡眠中の心拍数を読み取るだけで、ヘルスケアへの書き込みは行いません。読み取った値と、そこから求めた日ごとの判定（4つの印のいずれか）は、Apple Watch の中（このアプリ専用の保存領域）にのみ保存し、最大61日分を保持します。iPhone、当方のサーバー、その他の第三者には送信しません。当方がこれらの値を閲覧・取得することはできません。

2-32. 利用目的の限定

ヘルスケアから読み取ったデータは、今日の調子の印を表示するためだけに使い、広告・マーケティング・データの販売その他の目的には使いません。アカウントの登録は不要で、分析 SDK・広告 SDK は使用していません。

2-33. 課金情報

買い切りの購入・復元はApple の StoreKit を通じてのみ行われます。当方はクレジットカード番号その他の決済情報を取得しません（Apple が処理します）。お試し期間の残り日数は、Apple Watch の中に保存した最初の起動日をもとに計算します。

DayDay

2-34. アプリ内で記録される情報

ユーザーが録音した音声、そこから作る文字起こし、場面ごとの下書き、一日の報告、週のふり返り、貼り付けた要約、よく出る言葉、登録した自分の声の特徴（数値だけ）は、すべてユーザーの iPhone の中にのみ保存されます。Apple Watch で録音した音声は、iPhone が受け取るまで Apple Watch の中に保存され、iPhone への転送は Apple が提供する端末間の通信で行います。当方のサーバーはなく、当方がこれらの内容を閲覧・取得することはできません。アカウントの登録は不要で、分析 SDK・広告 SDK は使用していません。

2-35. 録音について

録音は、ユーザーが自分で始め、自分で止めます。アプリは背景から録音を始めることはできません。録音中は、iPhone と Apple Watch の OS が出すマイクの表示と、アプリの録音中の表示が出ます。録音には、会話の相手など、ユーザー以外の人の声が含まれることがあります。録音するのは、ユーザー自身が参加している会話だけにしてください。ほかの人の声を録音・保存・書き出すことについての責任は、ユーザーが負います。

2-36. 端末内での文字起こしと、報告づくり（Private Cloud Compute）

日本語の文字起こしは、Apple が提供する端末内の音声認識（SpeechAnalyzer）で iPhone の中だけで行い、音声は外部に送信されません。場面ごとの下書きは、Apple が端末上で動かす言語モデル（Foundation Models）で作ります。

一日の報告は、ユーザーが初回の案内または設定で「Private Cloud Compute を使う」を選んだときだけ、文字にした文章を Apple の Private Cloud Compute へ送って作ります（音声は送りません）。「よく出る言葉」に登録した言葉があるときは、表記をそろえるために、その言葉も一緒に送ります。週のふり返りも同じ仕組みで、その週の一日の報告の文章を Apple の Private Cloud Compute へ送って作ります（音声と文字起こしは送りません）。Apple は、Private Cloud Compute に送ったデータを要求の処理にのみ使い、保存せず、Apple も内容を閲覧できないと説明しています。当方のサーバーには送信されず、当方は送った内容を受け取りません。「端末内だけで使う」を選ぶと、この送信は行われず、報告は簡易な形になり、週のふり返りは作りません。Private Cloud Compute は、対応する端末と OS だけで使え、Apple の定める利用上限があります。外部の AI 提供者へのデータの送信は行いません。

2-37. コピー・書き出し・共有

「AI に貼る用にコピー」は、文字起こしに整理用のプロンプトを付けて端末のクリップボードに入れる機能です。ユーザーが自分で外部の AI アプリなどに貼り付けたときに限り、その文章は、貼り付けた先のサービスの定めに従って扱われます。日ごとの書き出し（音声の原本・文字起こし・録音の日時と各ファイルの指紋〔SHA-256〕）は、ユーザーの操作により端末内にファイルを作成し、共有シート等でユーザーが選んだ宛先へ渡すもので、当方のサーバーには送信されません。

2-38. 許可を求める機能

次の機能は、ユーザーが許可した場合に限り使います。マイク（録音）・音声認識（文字起こし）・通知（録音の開始と終了の知らせ。内容は表示しないよう設定できます）・Face ID／パスコード（アプリを開くときの認証。生体情報を当方が取得することはありません）・カレンダーの予定の読み取り／モーションとフィットネス／位置情報（いずれも、下記の「報告の手がかり」をオンにしたときだけ）。

2-39. 自分の声の登録（任意）

「自分の声を登録」を行うと、読み上げた声から、声の特徴を表す数値だけを作って iPhone の中に保存し、録音の中の自分の発言に印を付けるために使います。読み上げた音声は保存しません。この数値は端末の外へ送信されず、いつでも消せます。

2-40. 保存期間と削除

音声の保存期間は、ユーザーが初回の案内で選び（文字起こし後すぐ消す／30日で消す／ずっと残す）、設定からいつでも変えられます。音声・文字起こし・報告は、日ごと・期間ごと・すべてを、アプリの中でいつでも消せます。アプリを削除すると、iPhone と Apple Watch に保存した記録は消去されます。iCloud への同期・バックアップの仕組みは設けていません（録音の音声と自分の声の登録は、端末のバックアップにも含めません。文字起こし・報告などの記録は、ユーザーの端末のバックアップの設定に従います）。

2-41. 課金情報

買い切りの購入・復元はApple の StoreKit を通じてのみ行われます。当方はクレジットカード番号その他の決済情報を取得しません（Apple が処理します）。録音できる日数（最初の3日分）は、iPhone の中に保存した録音の日付から数え、当方には送信されません。購入管理のための第三者サービスは利用していません。

2-42. 報告の手がかり（任意）

設定の「報告の手がかり」でオンにした場合に限り、次の情報を、一日の報告を作る手がかりとして使います（初期設定はすべてオフです）。

  • カレンダーの予定：録音の時間帯と重なる予定の題・場所・参加者の名前を、iPhone の中で読みます。
  • 動き：歩いている・乗り物に乗っているといった記録を、報告を作るときに iPhone の中で読みます。
  • 場所：録音している間だけ、録音の1本（約10分）ごとに1回、iPhone または Apple Watch でおおよその位置（約100メートルの精度）を取り、録音の記録と一緒に端末の中に保存します。位置情報の許可は「使用中のみ」だけを求め、録音していないときの位置は取りません。

位置から付近の地名を調べるときに、位置の座標を Apple の地名検索に送ります。「Private Cloud Compute を使う」を選んでいる場合、予定の題・場所・参加者の名前、付近の地名、移動の有無は、文字起こしと一緒に文章として Apple の Private Cloud Compute に送られます（座標そのものは送りません）。これらの情報が当方に送信されることはなく、第三者に提供することもありません。位置は、日ごと・期間ごとの削除で録音の記録と一緒に消え、「すべてのデータを消す」で、調べた地名の記録も消えます。
